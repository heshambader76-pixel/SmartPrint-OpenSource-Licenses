# SmartPrint Pro - Open-Source Licenses and Covered Sources

This **public repository** hosts third-party open-source notices and covered source materials associated with SmartPrint Pro. It does **not** contain the proprietary SmartPrint app, the private Android Studio project, billing source code, credentials or signing keys.

## Public source and notices

- [SmartPrint Pro 0.7.0 - Covered Sources release](https://github.com/heshambader76-pixel/SmartPrint-OpenSource-Licenses/releases/tag/v0.7.0)
- [Download covered-source archive (ZIP, approximately 1.08 GB)](https://github.com/heshambader76-pixel/SmartPrint-OpenSource-Licenses/releases/download/v0.7.0/SmartPrint-Pro-0.7.0-Covered-Sources.zip)

The v0.7.0 release describes LibreOffice-related source materials, covered modifications, font sources, third-party notices and build-provenance documentation. These are supplier and project-provided materials; their presence alone does **not** establish full license compliance for every component.

## SmartPrint Pro 0.8.0 status (26 November 2026)

The app's Open Source Licenses action opens the public v0.7.0 release. During a Samsung S24 test, the owner verified that the link opens this public GitHub repository. The app's 0.8.0 source delivery is private and **must not** be uploaded here.

For the latest detailed source-inventory comparison and remaining legal/provenance checks, see [the v0.8.0 licensing evidence review](VERSION-0.8.0-REVIEW.md). The published archive currently carries the **0.7.0** release identifier. It has not yet been independently reconciled against the final 0.8.0 binary and component manifest. Do not describe it as verified complete corresponding source for 0.8.0 until that reconciliation is performed.

## Licensing and provenance review still outstanding

1. **OpenSymbol font (102.12):** verify the authoritative applicable licensing terms for the exact distributed font and corresponding source. Do not assume an OFL grant.
2. **LibreOffice and other native binaries:** establish a component-by-component match between the distributed binaries, exact source versions, local patches, build scripts and dependency sources. Existing broad source archives alone do not prove full correspondence. Verify the `libsqlite3.so` 3.53.0 source/build provenance and NSS/NSPR/runtime coverage.
3. **Original app icons and logo:** confirm the owner's rights to distribute the retained graphics. This is an app-asset provenance check and not a claim that those proprietary assets belong in the covered-source archive.
4. **Third-party notices and licensing scope:** verify against the final 0.8.0 build and update or publish any notices and corresponding sources that changed since v0.7.0.
5. **Access and packaging:** confirm the public archive is downloadable and that required notices/source offers remain accessible in the manner required by each applicable license.

These items remain under review and are not represented as completed or legally approved. The pre-existing 0.7.0 documentation in the private app repository records this review status; a newer public source package should be published only after its exact contents have been checked for proprietary code and secrets.
