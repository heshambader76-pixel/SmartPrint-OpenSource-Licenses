# SmartPrint Pro 0.8.0 — third-party licensing evidence

Audit date 26 November 2026. The [Hebrew audit report](AUDIT-0.8.0.he.md) contains the decision table and the evidence required to resolve open items. Scope is the owner-approved ARM64 APK under build commit `21b023eb73f7fd34221ba6b28ef6adf869b7af04` and the associated development package.

## Verified

- The final APK was reconstructed and hashed. Its 14 ELF files, 34 fonts, 53 non-font Office resource entries and 60 retained license entries match 0.7.0. The 41 removed HTML wrappers were presentation copies. The public [notice index](notices-0.8.0/README.md) gives direct access to 59 original notice and metadata files. [APK evidence](evidence-0.8.0/apk-payload.tsv)
- All 14 ARM64 native libraries match F-Droid LibreOffice 26.2.6.3 build 131 byte-for-byte. The 14 emulator libraries in the development package match build 129. The public 1,076,888,482-byte archive was downloaded and checked, and its build 131 source tar matches the hash in the signed F-Droid index, including the nested source archives and the covered Java and registry modifications used by 0.8.0. [Archive evidence](evidence-0.8.0/covered-archive.tsv) · [Native build inputs](evidence-0.8.0/native-source-inputs.tsv) · [Signed-index evidence](evidence-0.8.0/fdroid-signed-index.tsv) · [Official F-Droid APK](https://f-droid.org/repo/org.documentfoundation.libreoffice_131.apk)
- The 95 resolved Android runtime artifacts match the recorded hashes. For 94 artifacts, matching class descriptors were located in the final DEX files. The remaining artifact is the empty Guava placeholder. All 42 catalogued supplier notices match the original artifact bytes. Three Firebase POM links now point to their verified Google Maven locations. Google SDK terms remain distinct from third-party open-source notices. [Dependency evidence](evidence-0.8.0/android-runtime.tsv) · [DEX and notices](evidence-0.8.0/android-dex-notices.tsv) · [POMs](evidence-0.8.0/maven-poms.tsv)
- The OpenSymbol 102.12 TTF matches the pinned upstream binary hash. Its public preferred SFD source matches the pinned upstream SFD. The tested Debian font has identical Unicode mapping coverage and outlines for all 1,062 mapped codepoints. Debian describes the SFD as MPL-2.0 with some Apache-2.0 material. [Font evidence](evidence-0.8.0/font-identity.tsv) · [Upstream source](https://github.com/LibreOffice/core/tree/8221e31b3ac356a1623c672912a3d2b492f7e3d1/extras/source/truetype/symbol)

## Still open

- **GAP — native static linkage.** The confirmed F-Droid recipe and archived source inputs do not identify every static link input, applied patch and compilation flag. A per-component link record and build metadata from the F-Droid or upstream builder are required. The shared SQLite 3.53.0 binary identifies the same Fossil source as the included standalone source, while LibreOffice's separate source recipe names a 3.53.4 amalgamation. The build recipe for the shared library is still needed. [ELF evidence](evidence-0.8.0/elf-linkage.tsv) · [Pinned F-Droid recipe](https://gitlab.com/fdroid/fdroiddata/-/blob/acea224aa0e9dab9a85ba8072b8293e753c4fa97/metadata/org.documentfoundation.libreoffice.yml#L6984)
- **LEGAL_REVIEW — OpenSymbol.** The exact font and preferred source are identified. Obtain documentation from TDF font maintainers or applicable rights holders on the grant and notice coverage for the exact redistributed TTF and all named contributions, including the Google glyphs and the Takeshi Abe and Ming Hua contributions absent from Debian's named attribution paragraph. [Detailed rights evidence](AUDIT-0.8.0.he.md)
- **OWNER_CONFIRMATION — graphics.** Confirm which creation, assignment or license records cover the 13 owner artwork files listed in the inventory. [Graphic resource fingerprints](evidence-0.8.0/graphics.tsv)

The existing v0.7.0 archive is useful for supplying the verified unchanged covered-source material for 0.8.0. The audit leaves the stated source-to-binary and rights questions open.
